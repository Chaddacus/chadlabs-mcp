BookkeepingMCP

The QBO escape valve for solo bookkeepers. Pulls structured data out of invoice emails, categorizes uncategorized transactions, and drafts the chase emails you'd otherwise write by hand — inside whichever AI host you already use.

Bring your own model

The MCP server makes zero outbound LLM calls. It exposes prompts, a small SQLite vendor memory, and a chart of accounts — your AI host does the inference using your own model credentials. Cross-host-verified on:

Claude Desktop Goose Cursor Codex CLI Continue + Ollama LM Studio

No marketplace markup on LLM tokens. You pay Anthropic / OpenAI / OpenRouter directly — or run a local model and pay nothing per request.

What it does

invoice_extract

Paste an invoice email, get back vendor / amount / currency / line items / category — all from the chart of accounts, with confidence.

txn_classify

Hand it a batch of bank transactions, get one classification per row with confidence and reason. Vendor hints are honored.

chase_draft

Client name + list of missing receipts in, ready-to-send subject + markdown body + plain body out. Tone selectable.

vendor_lookup / remember

Fuzzy-matched vendor canonicalization (Jaro-Winkler ≥0.85) stored in local SQLite. Categorization stays consistent across sessions.

chase_log_record

Audit log of every chase email you've sent, queryable by client and transaction.

bookkeeping://categories

Resource with a 30-line small-business chart of accounts the prompts hand to your host LLM so categories stay consistent.

Quickstart

You'll need Node 20+ and any MCP-capable host (Claude Desktop, Goose, etc.). On launch day the npm package is one line:

npx -y @chadlabs/bookkeeping init
npx -y @chadlabs/bookkeeping doctor

doctor prints the exact config snippet for Claude Desktop and Goose. Paste it, restart the host, you're live. License key activates the full feature set.

Privacy

Invoices, transactions, and client info live in a local SQLite database at ~/.chadlabs/bookkeeping/db.sqlite on your machine. The server has no outbound network calls except the optional once-per-day license validation. Full data-flow + the static-deps proof (no @anthropic-ai/sdk, no openai, no @google/generative-ai in the package) ship with the v0.1 npm release.
